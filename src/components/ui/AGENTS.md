# UI Component Library

Reusable UI components following hexagonal honeycomb design system.

## Design System Constraints

- **Colors**: Pastel yellows (#FCD34D) and charcoal blacks (#1F2937)
- **Shapes**: Hexagonal patterns throughout (see globals.css for hex geometry)
- **Animations**: Use Framer Motion for consistency
- **Typography**: Inter font family with honey gradient effects

## Component Patterns

- All interactive components should have hover/focus states
- Use Tailwind's arbitrary values for hexagon-specific styling
- Accessibility: Include ARIA labels and keyboard navigation
- Mobile-first: Design for small screens, enhance for larger

## Honeycomb Utilities

Check `globals.css` for hexagon clip-path utilities before creating new ones.
